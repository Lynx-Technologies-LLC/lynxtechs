# LXDIO33-16

> Sample content. Replace with the finalized module specifications and part
> numbers; always refer to the datasheet for production designs.

The **LXDIO33-16** is a compact 16-channel digital I/O module for EtherCAT
networks, operating at 3.3 V logic levels.

## At a glance

| Feature | Value |
| --- | --- |
| Channels | 16 digital I/O |
| Logic level | 3.3 V |
| Interface | EtherCAT (IN / OUT ports) |
| Form factor | PCB module |
