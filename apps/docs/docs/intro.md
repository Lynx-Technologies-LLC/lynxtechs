# Lynx Technologies Documentation

Welcome to the documentation hub for **Lynx Technologies**. These docs cover the
**LXMASTER** Linux EtherCAT master software (API reference, tutorials, example
projects, and release notes) as well as the **EtherCAT hardware modules** and how
to integrate them into your own designs.

## What's in these docs

- **[LXMASTER Software](./lxmaster/overview.md)** - the Linux EtherCAT master
  stack: overview, getting started, tutorials, example projects, the API
  reference, and release notes.
- **[EtherCAT Basics](./ethercat-basics/overview.md)** - a high-level
  introduction to EtherCAT concepts, devices, and communication.
- **[Hardware](./hardware/overview.md)** - the EtherCAT hardware module family,
  PCB integration guidance, per-module tutorials, and example projects.

## How this documentation is organized

The site uses an **autogenerated sidebar**: navigation is built directly from the
folder structure under `docs/`. This keeps maintenance low as the documentation
grows.

Some sections are **generated by automation** and should not be hand-edited:

- `lxmaster/api` - the LXMASTER C++ API reference, generated from the public
  headers in the `lxmaster` repository (Doxygen -> Markdown) and published as a
  versioned release artifact. Only the user-facing API surface is included.
- `lxmaster/release-notes` - pulled from the `lxmaster` GitHub Releases.
- `lxmaster/examples` - synced from the `lxmaster-demos` repository.

### Adding a new page

Drop a `.md`/`.mdx` file into the relevant section folder. It appears in the
sidebar automatically. Use the `sidebar_position` frontmatter field to control
ordering within a section.

### Adding a new section

Create a folder under `docs/` and add a `_category_.json` file:

```json
{
  "label": "My New Section",
  "position": 5,
  "link": { "type": "generated-index" }
}
```
